#  Simulador de Carreira - Fórmula 1

Um simulador de carreira de Fórmula 1 desenvolvido em **JavaScript**, utilizando conceitos básicos de programação. O projeto permite criar seu próprio piloto, escolher uma equipe e disputar um campeonato contra os pilotos do grid.

##  Funcionalidades

- **Criação de piloto:** personalize seu piloto informando nome, idade e nacionalidade.
- **Atributos aleatórios:** seu piloto recebe valores de habilidade, visão e ritmo.
- **Escolha de equipe:** escolha uma das equipes disponíveis e substitua um de seus pilotos.
- **Classificação:** simulação de voltas para determinar o grid de largada.
- **Corridas:** resultados calculados com base nos atributos dos pilotos, no desempenho dos carros e em fatores aleatórios.
- **Sistema de pontuação:** os 10 primeiros colocados recebem pontos de acordo com o sistema utilizado na Fórmula 1.
- **Campeonato:** dispute até 24 etapas e acompanhe a classificação dos pilotos e das equipes.
- **Campeão:** ao final, veja quem conquistou o título da temporada.

##  Tecnologias utilizadas

- JavaScript
- Classes e objetos
- Arrays
- Funções
- Estruturas condicionais (`if`)
- Estruturas de repetição (`for` e `while`)
- `Math.random()` para simulações aleatórias
- `prompt()`, `alert()` e `console.log()` para interação.

##  Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo JavaScript em um ambiente que suporte `prompt()` e `alert()`.
3. Execute o código.
4. Siga as instruções exibidas para criar seu piloto e iniciar a carreira.

**Observação:** o projeto foi desenvolvido para funcionar por meio de entradas e saídas no console e em caixas de diálogo, não possuindo interface gráfica própria.

##  Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação e aprofundar conhecimentos em JavaScript, utilizando um tema de interesse pessoal: a Fórmula 1.

O simulador também busca representar alguns elementos de uma temporada real, como desempenho dos carros, atributos dos pilotos, classificações, corridas e pontuação de campeonato.
